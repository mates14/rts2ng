What

Shared across both telescopes - one target, one set of coordinates. A value missing on one side is filled in from the other automatically; a value genuinely different on both (rare, but happens - e.g. a marginal position update applied to only one side) is never silently overwritten - shown here for review instead, applied to both sides only when you Save.

How

Per-camera observing script. Always per-telescope - D50 and SBT don't share cameras, so nothing here is synced. [*] default clears an override and falls back to that camera's own configured default.

When

Not really "when" - how the scheduler should place this target.

Advanced: telescope identity / proxy path (auto-detected, override only if wrong)
