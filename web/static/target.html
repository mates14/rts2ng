Target

Scripts

Per-camera observing script override for this target. A camera with no override falls back to its own device's configured default (rts2.ini's per-camera script setting) - click [*] default to clear an override and go back to that. Scripts are always per-telescope (D50 and SBT don't share cameras) - never synced with the peer.

Scheduling

Free-text key=value parameters read by the site's separate Python scheduler (not by rts2ng itself). Known keys: duration= (seconds, overrides the estimator), mag=, snr=, filters= (e.g. gri), count=, pscale= (priority timescale, days), type= (oneof/and/sim - compound-reservation mode across telescopes; sim is not yet acted on by the scheduler as of this page being written).

D50 / SBT sync

D50/SBT-specific, purely a browser-side convenience (see web/STATUS.md task 10 phase 2) - neither daemon knows the other exists. On load this always fetches the same target ID from the peer telescope (a same-origin Apache proxy path, preconfigured per site below) and keeps name/comment/priority/interruptible/ position-or-MPC-line/scheduling's type= in sync: a field missing on one side is filled in from the other immediately; a field present but genuinely different on both sides is never auto-written - the SBT value is shown here for editing (and saved locally only if you click Save), the other side is left untouched. Saving here also pushes these same fields to the peer. Enabled/bonus/the rest of scheduling stay deliberately per-telescope.
